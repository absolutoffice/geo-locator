# Resultados de validación de geoLocator 1.0.1

Este directorio contiene los **resúmenes aptos para Git**, generados mediante `bash tools/verify-1.0.1.sh <php-binario> [--release]` desde la raíz del proyecto.

Se crearán los archivos `1.0.1-php84.md` y `1.0.1-php85.md` al ejecutar la suite con esos intérpretes; no se incluyen resultados ficticios ni plantillas marcadas como superadas. Los logs detallados se guardan en `var/validation/` y no se versionan.

La guía, los criterios y los comandos completos están en [VALIDACION-1.0.1.md](../VALIDACION-1.0.1.md).
